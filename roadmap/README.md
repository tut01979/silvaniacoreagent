# Roadmap Oficial — Ecosistema Silvania AI

> Documento vivo de evolución de producto. Pensado para que los primeros usuarios (*early adopters*) y futuros inversores vean el progreso continuo, las prioridades reales y el orden lógico de consolidación.

---

## Principio Rector: Consolidar antes de Escalar
Para crecer de forma sólida sin dispersar recursos ni generar deuda técnica o legal, el ecosistema avanza por **fases secuenciales basadas en tracción real**:

1. **Fase 0 — Validación y Calidad Visual (AHORA):**
   - **Marketing Agent** con vídeos fluidos, coherentes y de alto impacto para atraer tráfico orgánico y prospectos.
   - **Setter IA (Modo Validación / Early Adopters)** con Unipile + Telegram HITL + Google Calendar para conseguir los primeros 20–50 usuarios activos y feedback real **antes de darnos de alta y activar cobros**.
2. **Fase 1 — Monetización y Lanzamiento "Combo Microempresario All-in-One":**
   - Alta legal/fiscal y lanzamiento de la oferta unificada **Silvania Todo-en-Uno (CoreAgent + Setter IA + Marketing + Widget Web)**:
     - **Oferta Fundadores (Primeros 100 clientes):** 50 €/mes (precio congelado de por vida mientras mantengan la suscripción activa).
     - **Precio Estándar:** 60 €/mes (frente a los 70–100 €/mes que cobra el mercado solo por un setter aislado).
   - Widget Web / Webhook embebible para capturar y agendar leads en la web del cliente.
   - Base de conocimiento sin código conectada a carpetas de Google Drive.
   - Lanzamiento de **Silvania Network (`/comunidad`)** para retener usuarios con noticias oficiales + networking profesional.
3. **Fase 2 — Salto Audiovisual y Educación Interactiva:**
   - **Marketing Agent Nivel 2–3:** clips generativos (video-to-video / image-to-video), múltiples personajes y voces diferenciadas por personaje.
   - **Eva Agent:** mundos interactivos de aprendizaje lúdico + análisis de pronunciación y lectura labial.
4. **Fase 3 — Escala y Expansión Internacional:**
   - Infraestructura SaaS multi-tenant, métricas auditables de ARR/retención y alianzas educativas/empresariales.
5. **Fase 4 — Mercados de Capitales / Web3 (Largo plazo, sujeto a tracción y marco legal):**
   - Evaluación de módulo Web3 (utilidad/gobernanza) o estructura corporativa para financiación institucional, siempre con asesoría legal/regulatoria previa (MiCA / CNMV / SEC).
