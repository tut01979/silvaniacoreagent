# rrhh-perfil-contratacion

## Descripción
Genera un perfil de contratación detallado para el departamento de RRHH basado en el puesto y el área.

## Cuándo usarla
Úsala cuando el usuario solicite tareas relacionadas con rrhh-perfil-contratacion.

## Instrucciones paso a paso para el agente
1. Proporcionar el nombre del puesto.
2. Indicar el área o departamento.
3. Especificar el nivel del puesto (Junior, Senior, Manager).
4. Indicar la modalidad de trabajo (remoto, presencial, híbrido).

## Entregables que debe generar
Reportes, archivos o confirmaciones de las acciones tomadas en base a las instrucciones.
