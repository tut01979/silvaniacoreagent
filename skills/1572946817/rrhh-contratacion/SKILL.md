# Skill: RRHH - Selección de Perfil de Contratación

## Descripción
Ayuda a definir el perfil ideal de candidato según el área y el puesto. Genera descripciones de puesto, requisitos, preguntas de entrevista y plantillas de evaluación.

## Cuándo usarla
- Cuando el usuario pida crear o ajustar un perfil de contratación
- Cuando diga "necesito contratar un X para el área Y"
- Cuando pida plantillas de entrevista, job description o evaluación de candidatos

## Instrucciones para el agente

1. **Preguntar lo esencial** (si no lo da el usuario):
   - Área / departamento
   - Nombre del puesto
   - Nivel (junior / mid / senior / lead)
   - Modalidad (presencial / híbrido / remoto)
   - ¿Es urgente?

2. **Generar siempre estos entregables**:
   - Job Description (descripción del puesto)
   - Requisitos obligatorios vs deseables
   - Competencias clave
   - 8-12 preguntas de entrevista (técnicas + soft skills)
   - Plantilla de evaluación de candidato (puntuación 1-5)
   - Texto de publicación para LinkedIn / InfoJobs (versión corta)

3. **Guardar en Drive**:
   - Crear carpeta: `silvania/skills/rrhh-contratacion/plantillas/[puesto]-[fecha]`
   - Guardar cada entregable como Google Doc o Sheet según convenga

4. **Estilo**:
   - Profesional, claro y orientado a resultados
   - En español (salvo que pidan otro idioma)
   - Evitar jerga innecesaria

## Ejemplo de uso
Usuario: "Crea el perfil para un desarrollador backend senior en el equipo de producto"
→ El agente genera todo el paquete y lo deja organizado en Drive.
