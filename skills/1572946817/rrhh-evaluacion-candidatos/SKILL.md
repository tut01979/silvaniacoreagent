# rrhh-evaluacion-candidatos

## Descripción
Skill para el departamento de RRHH que gestiona la evaluación de candidatos.

## Cuándo usarla
Úsala cuando el usuario solicite tareas relacionadas con rrhh-evaluacion-candidatos.

## Instrucciones paso a paso para el agente

1. Preguntar al usuario por el nombre del candidato y el puesto al que aplica.
2. Solicitar al usuario los criterios de evaluación (ej: experiencia, habilidades técnicas, habilidades blandas, adecuación cultural).
3. Pedir al usuario que proporcione una calificación (ej: del 1 al 5) para cada criterio.
4. Generar un informe de evaluación del candidato con las calificaciones y comentarios.
5. Guardar el informe en Drive dentro de silvania/skills/rrhh-evaluacion-candidatos/informes/.
6. Presentar el informe al usuario y un enlace directo al archivo en Drive.


## Entregables que debe generar
Reportes, archivos o confirmaciones de las acciones tomadas en base a las instrucciones.
