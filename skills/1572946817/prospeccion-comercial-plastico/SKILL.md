# prospeccion-comercial-plastico

## Descripción
Skill para buscar empresas de plástico en España con fines comerciales.

## Cuándo usarla
Úsala cuando el usuario solicite tareas relacionadas con prospeccion-comercial-plastico.

## Instrucciones paso a paso para el agente

1. Preguntar al usuario si desea buscar por una provincia o comunidad autónoma específica, o en toda España.
2. Realizar una búsqueda web exhaustiva de empresas de fabricación o distribución de productos de plástico en la zona especificada.
3. Recopilar la siguiente información de cada empresa:
   - Nombre de la empresa
   - Sitio web (si disponible)
   - Dirección (si disponible)
   - Teléfono de contacto (si disponible)
   - Correo electrónico de contacto (si disponible)
   - Breve descripción de su actividad (si disponible)
4. Guardar la información recopilada en un archivo CSV o Google Sheet dentro de la carpeta `silvania/skills/prospeccion-comercial-plastico/resultados/`.
5. Presentar al usuario un resumen de las empresas encontradas y un enlace al archivo generado en Drive.


## Entregables que debe generar
Reportes, archivos o confirmaciones de las acciones tomadas en base a las instrucciones.
